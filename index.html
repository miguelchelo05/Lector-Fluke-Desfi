Normativas de Referencia

Estándares aplicables a equipos electromédicos y desfibriladores

  • IEC 60601-1: Requisitos generales para la seguridad básica y funcionamiento esencial de equipos electromédicos.
  • IEC 60601-2-4: Requisitos particulares para la seguridad básica y funcionamiento esencial de desfibriladores cardíacos.
  • Tecnovigilancia: Protocolos institucionales para el reporte de incidentes adversos con dispositivos médicos.

Validación de Pruebas de Seguridad

Criterios de aceptación para liberación de equipos

Parámetros críticos evaluados por el Fluke Impulse 7000DP:

  • Precisión de energía descargada (Margen permitido general: ± 15% o según fabricante).
  • Tiempo de carga del desfibrilador a energía máxima.
  • Pruebas de sincronismo (Cardioversión).
  • Análisis de forma de onda bifásica.
